# 结算与死因

> 中文为人工翻译; 英文原文来自 pixel-dungeon v1.9.1 源码。「贴图」列给出精灵表名与原始 tile 序号, 与贴图项目 sprites.json 的 `coords[tile]` 一一对应。

## ResultDescriptions

- `MOB` 在第 %d 层被%s杀死
- `BOSS` 在第 %d 层被%s杀死
- `WAND` 在第 %d 层被自己的%s杀死
- `GLYPH` 在第 %d 层被%s杀死
- `BOMB` 在第 %d 层被炸弹的爆炸炸死
- `TRAP` 在第 %d 层死于%s的放电
- `BURNING` 在第 %d 层被活活烧死
- `HUNGER` 在第 %d 层饿死
- `POISON` 在第 %d 层毒发身亡
- `GAS` 在第 %d 层死于毒气
- `BLEEDING` 在第 %d 层失血而死
- `OOZE` 在第 %d 层被腐蚀性黏液杀死
- `FALL` 在第 %d 层坠亡
- `WIN` 获得耶诺之护符
