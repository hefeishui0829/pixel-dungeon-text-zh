# 陷阱与机关

> 中文为人工翻译; 英文原文来自 pixel-dungeon v1.9.1 源码。「贴图」列给出精灵表名与原始 tile 序号, 与贴图项目 sprites.json 的 `coords[tile]` 一一对应。

## AlchemyPot

- `TXT_SELECT_SEED` 选择一颗种子扔进去

## Chasm

- `TXT_CHASM` 深渊
- `TXT_YES` 是的，我清楚自己在做什么
- `TXT_NO` 不，我改变主意了
- `TXT_JUMP` 你真的要跳进深渊吗？你很可能会死。

## Sign

- `TXT_DEAD_END` 你在这儿干什么？！
- `TXT_BURN` 你刚想读那块牌子，它就爆出了绿色的火焰。
